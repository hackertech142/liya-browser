## Usage statistics collection in Liya

By default, Liya sends some statistics about how it's used. Currently, these include:

* Your operating system and computer language
* When you installed Liya
* The version of Liya that you're using
* How often you use certain features in Liya
* An anonymous ID representing your installation of Liya

Collecting this data allows us to prioritize which devices and operating systems we test and which features we work on.

Liya does not send:
* Anything that can be used to personally identify you
* Any browsing history, passwords, or other data stored locally in Liya

If you want to opt-out of statistics collection, you can do so by going to the preferences page within Liya and de-selecting "send usage statistics".
